# Noviteq Brand Hub

The living identity system and creation toolkit for Noviteq Solutions.

## What is included

- Full brand foundations: strategy, logo, colour, typography, voice, accessibility and governance
- Interactive starters for letterheads, signatures, landing pages, emails, store themes, social/profile assets, forms and slides
- Approved primary and energy logo assets

Run `npm run dev` for the local Brand Hub or `npm run build` for a production build.
